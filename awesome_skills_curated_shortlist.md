# Awesome Skills Curated Shortlist

This shortlist is the small set of `awesome-skills` entries that currently match the Gemini-2 and shared-fabric development workflow best.

## Keep These First

- `code-reviewer`
  - Best for code reviews, regression checks, and identifying risky changes before merge.
- `testing-patterns`
  - Best for unit tests, factories, mocks, and tightening verification around refactors.
- `docs-architect`
  - Best for architecture writeups, internal manuals, and explaining the Gemini-2 stack clearly.
- `api-documenter`
  - Best for command/runtime/API documentation and future external-facing docs work.
- `frontend-developer`
  - Best for terminal UI, desktop shell, and interaction-layer changes.
- `backend-architect`
  - Best for runtime boundaries, services, state persistence, and orchestrator design.
- `workflow-orchestration-patterns`
  - Best for loop runtime, automation strategy, and long-running task design.
- `prompt-engineering`
  - Best for improving system prompts, agent routing prompts, and skill activation instructions.

## Why Not Use The Full 1200+ Library By Default

- Too many entries are still weakly categorized.
- Many skills are generic, overlapping, or domain-specific to workflows we do not use often.
- A smaller curated layer improves retrieval quality and lowers operator mental load.

## Current Recommendation

Use the curated layer first. Fall back to the full `awesome-skills` library only when the task clearly needs a niche domain skill that is not in this shortlist.
